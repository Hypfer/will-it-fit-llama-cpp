# Will it fit?

This vibecoded tool aims to answer the questions, normal people have when it comes to local LLMs.

"I have this GPU, what sensible thing can I run on this and how?"


It was written using local LLMs on an RTX 4090, which I've forced to look at the llama.cpp source code.
Plus big brother gemini fixing css.


No Strix Halo, no Macs, no other vaporware. Especially no shitty finetuned spam models.

Just "I have a nvidia gpu. What do I do. What real AI lab model can I run how?"


Take this with a huge pile of salt. For all you know, I am a clueless idiot.

This might never get updated and just serve outdated data, so make sure to verify that too.
